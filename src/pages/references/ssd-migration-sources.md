## 可公开的数据

[脱敏 CSV](/downloads/ssd-migration-samples.csv)包含 60 条样本，每个场景在 HDD 和 SSD 下各 10 条。时间单位全部为毫秒，列名保留测量对象。数据仅包含场景、存储类型、运行序号与耗时；不包含凭据、部署地址、主机名、数据集 ID 或实际查询内容。原始 PDF 不在此站点公开。

RAGFlow 日志的 chunks=30、total=90 在两组共 20 轮记录中相同；三个场景的前后日志均报告 success=10、failure=0。报告未提供足以确定并发负载的参数，也未附完整测试脚本。

## 统计核对

使用 CSV 中的逐轮值复算三组平均耗时及 Dify 检索的 P50、P95。降幅使用原始样本均值计算，与报告的百分比在保留两位小数后相符。

| 核对指标 | HDD | SSD |
| --- | ---: | ---: |
| RAGFlow 平均耗时 | 996.923 ms | 825.908 ms |
| Dify 检索平均耗时 | 1486.258 ms | 1316.453 ms |
| Agent started 平均值 | 682.258 ms | 567.691 ms |
| Agent TTFT 平均值 | 4060.248 ms | 3425.687 ms |
| Agent total 平均值 | 8766.225 ms | 6341.378 ms |

报告的 RAGFlow SSD 中位数为 828.59 ms，附录显示值复算为 828.595 ms；Agent HDD total 汇总为 8766.22 ms，附录显示值复算为 8766.225 ms。末位差异可能来自取舍方式或逐轮值已经四舍五入。文章沿用报告汇总值，不改变原始样本。

Dify 检索 P50 的复算值为 1456.745 和 1391.600 ms。P95 按排序后位置 `(n − 1) × 0.95` 线性插值，得到 2090.418 和 1517.020 ms，与汇总值相符。该计算方法与报告结果一致，不代表已经核验原脚本的实现。

## 结论范围

博客保留前后测试中观察到的改善，不沿用报告中“消除长尾”或“I/O 等待彻底消失”等更强的表述。10 轮数据不能验证高并发容量、长期稳定性或独立的存储因果效应。文中的节点级测量、缓存分组和并发测试属于后续验证方案。
